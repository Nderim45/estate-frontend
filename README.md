# Real Estate Platform

A comprehensive platform for viewing and managing real estate properties, allowing users to explore property listings, view details, and contact property agents.

## Table of Contents

- [Features](#features)
- [Demo](#demo)

## Features

- View real estate listings with images, prices, and descriptions.
- Search properties by type, price, and more.
- User authentication for users who want to post properties.
- Responsive design for mobile and desktop views.

## Installation

### Prerequisites

- **Node.js** (>= 16.x)
- **npm** or **yarn**
- Optional: **MongoDB** (for the backend if this is a full-stack project)

### Steps

1. Clone the repository:
    ```bash
    git clone https://github.com/Nderim45/estate-frontend.git
    ```

2. Navigate to the project directory:
    ```bash
    cd estate-frontend
    ```

3. Install the dependencies:
    ```bash
    npm install
    ```

4. Create a `.env.local` file and add the required environment variables (e.g., API keys, database URLs).

5. Start the development server:
    ```bash
    npm run dev
    ```

6. Open your browser and navigate to `http://localhost:3000`.

## Usage

Once the app is running:

- Explore the property listings on the homepage.
- Use the search filters to find properties by location, price, and type.
- Click on a property for detailed information, including agent contact details.
- If you want to add a property, log in and you can add it.
